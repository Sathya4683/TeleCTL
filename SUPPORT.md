# Support

## Where to ask

| What | Where |
|------|-------|
| Bug reports | [GitHub issue with the bug template](.github/ISSUE_TEMPLATE/bug_report.md) |
| Feature requests | [GitHub issue with the feature template](.github/ISSUE_TEMPLATE/feature_request.md) |
| "How do I…" questions | [GitHub Discussions](../../discussions) (Q&A category) |
| Security vulnerabilities | **Email security@wactl.example** — see [SECURITY.md](SECURITY.md) |
| Code of conduct violations | **Email conduct@wactl.example** — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## What this project does NOT provide

- **Production support contracts.** WACTL is a portfolio project. There
  is no SLA, no pager, no on-call.
- **Email support for usage questions.** Please use GitHub Discussions.
- **Custom integrations.** The plugin architecture is open — you can
  add your own commands — but we won't write bespoke code for you.
- **Hosting.** You run it yourself on your own AWS account.
